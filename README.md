# Jadavpur University Music Club (JUMC) Official Website

Welcome to the official repository for the Jadavpur University Music Club (JUMC) Full-Stack Website. This platform serves as the digital beating heart of our campus legacy—facilitating event showcases, ticket registrations, artist portfolios, and seamless club administration.

## 🚀 Features

- **Dynamic Landing Page**: Beautiful, responsive, and animated user interface built with Next.js, Tailwind CSS, and Framer Motion.
- **Event Management**: Browse upcoming events, view historical highlights, and manage ticket registrations.
- **Member Portals**: Dedicated access for Students, Performers, and Core Admins.
- **Robust Architecture**: Built on a highly scalable MERN + Next.js stack, strictly typed with TypeScript.
