# SEO & Accessibility

## Meta Tags
- Every page must have dynamic `<title>` and `<meta name="description">` tags utilizing Next.js Metadata API.
- Open Graph (OG) tags and Twitter Cards must be configured for rich link sharing.

## Semantic HTML
- Use proper heading hierarchy (`<h1>`, `<h2>`, `<h3>`). Only one `<h1>` per page.
- Wrap content in structural tags (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`).

## Sitemap & Robots
- Automatically generate `sitemap.xml` listing all canonical URLs.
- Provide a `robots.txt` to guide search engine crawlers.

## Accessibility (a11y)
- Add `aria-labels` to interactive elements missing text (e.g., icon buttons).
- Ensure high color contrast ratios for text.
