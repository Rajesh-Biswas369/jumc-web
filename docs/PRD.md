# Product Requirements Document (PRD)

## Project Overview
Jadavpur University Music Club (JUMC) Official Website and Portal.

## Objectives
- Showcase JUMC events, artists, and legacy.
- Facilitate event registration and ticket tracking.
- Provide a portal for performers, students, and club admins.

## User Personas
1. **Students/General Audience**: Can view upcoming events, purchase/register for tickets, and view past memories.
2. **Performers**: Can view their assigned slots, upload setlists, and communicate with organizers.
3. **Admins (Core Members)**: Can create/manage events, approve performers, and monitor ticket sales/registrations.

## Minimum Viable Deliverables
- Fully responsive and accessible landing page (Completed).
- Backend RESTful API for user authentication and event management.
- MongoDB database integration for persisting users and events.
- Admin dashboard for managing club activities.
